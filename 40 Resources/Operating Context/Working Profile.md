# Working Profile

Search tags: #context/working-profile #area/development #area/content #area/photography #area/business

## Role

Kofi works across full-stack software development, content creation, photography, product thinking, and business tooling.

## Working model

- Prefer precise, execution-focused output over broad commentary.
- Start with the smallest workflow that safely produces a usable result.
- Keep project context, decisions, evidence, and next actions distinguishable.
- Use repository evidence before making repository-dependent claims.
- Preserve durable knowledge in portable Markdown rather than relying on chat history.

## Engineering defaults

- React with the latest Vite for client applications.
- Node.js and Express for APIs and companion services.
- MongoDB and Mongoose for durable application data.
- Tailwind CSS for styling.
- TanStack Query for server state.
- Redux Toolkit only for global client state shared across UI regions.
- Vitest for frontend tests.
- Jest and Supertest for backend tests.
- Environment variables for secrets and environment-specific configuration.
- One root `package.json` unless a project explicitly requires another layout.

## Content creation

- Prioritise clear hooks, useful structure, concise delivery, and reusable short-form ideas.
- Keep technical content accurate and grounded in working examples or current evidence.
- Separate draft concepts from approved publishing copy.

## Photography

- Treat photography as both a creative practice and a repeatable production workflow.
- Keep shoot context, editing decisions, delivery requirements, and reusable references organised separately.

## Business

- Prefer systems that reduce repeated manual work and make the next action explicit.
- Keep business rules, customer-facing decisions, operational tasks, and project implementation details separated.
