# Software Development

Search tags: #area/development #engineering #mern

## Responsibility

Maintain reliable full-stack software systems, engineering workflows, development standards, and reusable technical knowledge across active projects.

## Default approach

- React and Vite for client applications.
- Node.js and Express for APIs and local services.
- MongoDB and Mongoose for durable application data.
- Tailwind CSS for styling.
- TanStack Query for server state and Redux Toolkit only for shared global client state.
- Vitest for frontend tests and Jest/Supertest for backend tests.
- Secrets and environment-specific configuration in environment variables.
- Repository evidence before repository-dependent conclusions.

## Operating standards

- Keep API and data-access logic outside React components.
- Prefer complete, copy-ready implementations over disconnected fragments.
- Use non-main branches for code-changing work.
- Run available tests, linting, type checks, builds, and runtime verification before publication actions.
- Record durable architecture and product decisions separately from implementation logs.
